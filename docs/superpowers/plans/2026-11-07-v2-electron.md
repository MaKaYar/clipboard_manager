# Clipboard Image Saver 2.0 Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. Executed via a Workflow (parallel module agents, then integration, test and review agents).

**Goal:** Replace the Tkinter app and the half-built Electron+Python hybrid with one Electron app: a gallery UI, Google Sheets sync, a per-user NSIS installer and auto-update from GitHub Releases.

**Architecture:** Electron main process does all work: polls `clipboard.readImage()` once per second, saves new images as `img_<n>.png`, optionally uploads to Drive and writes `=IMAGE()` into the first sheet cell containing a search term. The renderer is plain HTML/CSS/JS behind a `contextBridge` API. `electron-updater` checks GitHub Releases.

**Tech Stack:** Electron 45, electron-builder 26 (NSIS), electron-updater 6, `@googleapis/sheets`, `@googleapis/drive`, `google-auth-library`, `node --test`, Playwright `_electron` for E2E. No bundler, no framework, CommonJS.

**Spec:** `docs/superpowers/specs/2026-11-07-v2-design.html` (approved mockups; UI copy is Russian and must match it).

## Global Constraints

- Windows only target. Node built-ins + listed deps only. No new dependencies without strong reason.
- UI text in Russian, matching the spec mockup wording.
- Light and dark theme follow the OS (`prefers-color-scheme`), tokens on `:root`.
- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true` for the window. Renderer never gets Node.
- All persistent state in `app.getPath('userData')` (`%APPDATA%\Clipboard Image Saver`). Env `CIS_USER_DATA` overrides userData (tests). Never write next to the exe.
- File naming: `img_<n>.png`, n = max existing n in folder + 1 (start at 1). Same as the Python version.
- Starting the watcher must NOT save whatever image is already in the clipboard (baseline hash taken at start).
- Google scopes: `https://www.googleapis.com/auth/spreadsheets`, `https://www.googleapis.com/auth/drive.file`.
- Releases: version `1.0.<github.run_number>`, tag `v1.0.N`, installer `ClipboardImageSaver-Setup-<version>.exe` + `latest.yml`, published (not draft) to `MaKaYar/clipboard_manager`.

## Interfaces (contract every task codes against)

```js
// src/main/watcher.js
nextFilename(names: string[]) -> string            // ['img_2.png','img_10.png','x.png'] -> 'img_11.png'; [] -> 'img_1.png'
class ClipboardWatcher extends EventEmitter {
  constructor({ clipboard, intervalMs = 1000, fs = require('fs') })  // clipboard: Electron clipboard (injectable for tests: needs readImage())
  start(folder: string) -> void     // mkdir -p folder, baseline = hash(current image), begin polling; idempotent
  stop() -> void
  get running(): boolean
  get folder(): string|null
  pollOnce() -> {path, filename}|null   // exported for tests; saves if new non-empty image
  // events: 'saved' {path, filename, savedAt: number(ms)} ; 'error' {message}
}
// image identity = sha1 of image.toBitmap(); empty image (isEmpty()) ignored; save = image.toPNG()

// src/main/settings.js
DEFAULTS = { folder: '', recentFolders: [], minimizeToTray: true, launchAtLogin: false, notifyOnSave: false,
  google: { enabled: false, authMode: 'oauth', credentialsFile: '', clientSecretFile: '',
            spreadsheetId: '', sheetName: 'Sheet1', searchTerm: 'add', driveFolderId: '' } }
loadSettings(dir: string) -> settings        // reads dir/settings.json, deep-merged over DEFAULTS; corrupt file -> DEFAULTS
saveSettings(dir: string, settings) -> void  // atomic write (tmp + rename)
addRecentFolder(list: string[], folder: string, max = 10) -> string[]  // dedupe (case-insensitive on win), newest first
importLegacy(legacyJsonPath: string, tokenPath: string|null) -> Partial<settings.google>  // maps snake_case python keys
// token for OAuth lives at dir/google-token.json

// src/main/google-sync.js
a1(col: number, row: number) -> string               // a1(0,0)='A1', a1(26,4)='AA5'
findCell(values: string[][], term: string) -> {row, col}|null   // first cell (row-major) whose text contains term, case-insensitive
parseSpreadsheetId(input: string) -> string          // accepts full URL or bare ID
normalizeToken(json: object) -> {access_token?, refresh_token, expiry_date?}  // accepts python google-auth format (token, refresh_token, expiry ISO) or node format
class GoogleSync {
  constructor(googleSettings, { tokenPath: string, openExternal: (url)=>Promise })
  async init() -> void            // service: GoogleAuth keyFile; oauth: client secret + token file, refresh; if no/invalid token -> loopback OAuth on 127.0.0.1:<random port>, persists token (also on 'tokens' event)
  async uploadAndUpdate(imagePath: string) -> { fileId, link, cell }   // cell like "'Sheet'!C14"
}
// Upload: drive.files.create(name=basename, parents=[driveFolderId] if set, supportsAllDrives), then permissions.create anyone/reader (ignore failure),
// link = https://drive.google.com/uc?export=view&id=<id>, formula =IMAGE("<link>"); read range "'<sheet>'" values, findCell, update USER_ENTERED.
// No cell found -> throw Error('Не найдена ячейка с «<term>» на листе «<sheet>»'). Retries: 3 attempts with backoff on 429/5xx/network.

// src/main/gallery.js
listRecent(folder: string, limit = 40) -> [{path, filename, mtimeMs}]   // img_*.png only, newest first by n desc; missing folder -> []

// src/main/updater.js
initUpdater({ send: (channel, payload)=>void, log }) -> { check(): Promise, install(): void }
// only when app.isPackaged; autoDownload; checks at start and every 4h; sends 'update:state' {state:'checking'|'available'|'downloading'|'downloaded'|'none'|'error', version?, percent?, message?}

// src/preload.js  -> window.api
getState() -> Promise<{settings, running, folder, stats:{session, inFolder, synced}, gallery:[{path,filename,mtimeMs,sync?:'pending'|'ok'|'error', syncError?, cell?}], version, googleStatus:'off'|'connecting'|'ok'|'error', googleError?, update?}>
start() / stop() -> Promise<{ok, error?}>
pickFolder() -> Promise<string|null>      // also sets settings.folder + recent
setFolder(path) -> Promise<void>
openFolder() / openImage(path) / showInFolder(path) / copyImage(path) / retrySync(path) -> Promise<void>
saveSettings(partial) -> Promise<{ok, error?}>   // merges, applies login item, re-inits Google
pickFile() -> Promise<string|null>        // JSON picker
checkForUpdates() / installUpdate() -> Promise<void>
on(channel, cb) -> unsubscribe            // channels: 'state' (full state push), 'log' {ts, level:'info'|'ok'|'error', text}, 'update:state'
```

Tray: icon `tray-on.png` while running, `tray-off.png` paused; menu «Открыть», «Пауза»/«Старт», «Открыть папку», «Выход». Closing the window hides to tray when `minimizeToTray`. Second instance focuses the window. If `settings.folder` is set, watching auto-starts on launch.

## Review Focus

- Clipboard holds a huge screenshot (4K+): polling must not leak memory or block UI; hash per poll is fine, no extra copies kept.
- Save folder deleted or on disconnected OneDrive while running: error logged, watcher keeps running, no crash loop spam (log once per distinct error).
- Google token revoked/expired: re-auth flow starts instead of silently failing every image (test: `invalid_grant` → token file removed, status error with message).
- Sheet has no cell with the term left: per-image error badge, retry available, other images still saved locally.
- Second app launch while first runs in tray: focuses existing window, no second watcher writing duplicate `img_n`.
