Clipboard Image Saver 2.0

Одно приложение вместо двух, нормальный интерфейс с галереей сохранённых скриншотов, установщик для Windows и автообновление из GitHub Releases.

Главное окно

Окно отвечает на три вопроса: идёт ли отслеживание, куда сохраняется, что уже сохранено и ушло ли в Google Sheets. Лог прячется вниз, раскрывается по клику.

Трей

Закрытие окна сворачивает в трей, отслеживание продолжается. Иконка серая на паузе, цветная при работе. Меню трея: Открыть, Пауза/Старт, Открыть папку, Выход. По желанию: системное уведомление на каждое сохранение (по умолчанию выключено).

Рекомендую

Только Electron (Node)

Буфер обмена читает сам Electron (clipboard.readImage()), Google Sheets/Drive через пакет googleapis. Python удаляется целиком.

Установщик: electron-builder + NSIS. Автообновление: electron-updater из GitHub Releases, это стандартная связка. Минус: установщик ~80 МБ, логику Google (170 строк) переписываю на JS.

Альтернатива

Только Python (PySide6)

Оставляю текущую логику, меняю Tkinter на Qt с нормальной стилизацией. Установщик Inno Setup.

Автообновление пишу сам: проверка GitHub API, скачать Setup.exe, тихая установка. PyInstaller-сборки часто ловят ложные срабатывания антивирусов.

Не советую

Electron + Python-воркер

Текущий экспериментальный путь. Нужно собирать и Python-exe, и Electron, и связывать их через stdout.

Две сборки, два набора зависимостей, больше мест для поломок.

Установка и обновление

  1. Установка. ClipboardImageSaver-Setup-1.0.N.exe, ставится в профиль пользователя без прав администратора, ярлык в «Пуск» и на рабочий стол.
  2. Релиз. Пуш в main → GitHub Actions собирает установщик с версией 1.0.<номер сборки> и публикует релиз с latest.yml. Как сейчас: пуш = релиз.
  3. Проверка. Приложение проверяет GitHub при старте и раз в 4 часа, качает обновление в фоне.
  4. Применение. Плашка «Скачана версия X». Установится при выходе или по кнопке «Перезапустить сейчас».

Без подписи кода Windows SmartScreen покажет «Неизвестный издатель» при первой установке. Сертификат стоит денег, это можно добавить позже. Обновления работают и без подписи.

Как я буду тестировать

  • Юнит-тесты на нумерацию файлов, сравнение картинок, настройки, поиск ячейки в таблице (node --test, без лишних библиотек).
  • Запуск настоящего приложения через Playwright: кладу картинку в буфер обмена, проверяю, что файл появился и карточка возникла в галерее. Скриншоты окна в обеих темах.
  • Локальная сборка установщика, установка, запуск, удаление.
  • Автообновление: ставлю версию 1.0.0, поднимаю локальный сервер с 1.0.1 и проверяю, что приложение скачало и поставило обновление.
  • Google-синхронизацию на твоей таблице проверю только с твоего разрешения: она пишет в реальную таблицу и Диск.
